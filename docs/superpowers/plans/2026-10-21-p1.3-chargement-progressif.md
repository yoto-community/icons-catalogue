# P1.3 — Chargement progressif du catalogue par shards (plan d'implémentation)

Spec de référence : `docs/superpowers/specs/2026-10-21-p1.3-chargement-progressif-design.md`

**Objectif** : afficher des icônes avant la fin du téléchargement complet, en
publiant le manifeste `index.json` + les shards par source, et en fusionnant
progressivement côté front. Total téléchargé ~inchangé ; recherche/tri globaux
disponibles une fois tout chargé. `icons.json` n'est plus publié (remplacé par
le manifeste + shards). Les tests d'abord (TDD) pour tout le code front.

Créer `site/src/api/manifest.ts` :
```ts
/**
 * Manifeste publié (`index.json`) : types, garde de forme et ordre de
 * chargement des shards par source (P1.3).
 */
export interface ManifestSource {
  id: string;
  count: number;
}

export interface CatalogueManifest {
  schemaVersion: number;
  catalogVersion: string;
  counts: { total: number };
  sources: ManifestSource[];
}

function isManifestSource(value: unknown): value is ManifestSource {
  if (typeof value !== 'object' || value === null) return false;
  const source = value as Record<string, unknown>;
  return typeof source.id === 'string' && typeof source.count === 'number';
}

/**
 * Garde de forme minimale du manifeste : ce dont le front a besoin pour
 * charger les shards. On tolère les champs supplémentaires (shards par
 * catégorie, searchIndex…) qui ne sont pas publiés.
 */
export function isCatalogueManifest(value: unknown): value is CatalogueManifest {
  if (typeof value !== 'object' || value === null) return false;
  const manifest = value as Record<string, unknown>;
  if (typeof manifest.schemaVersion !== 'number') return false;
  const counts = manifest.counts as Record<string, unknown> | undefined;
  if (typeof counts?.total !== 'number') return false;
  if (!Array.isArray(manifest.sources) || manifest.sources.length === 0) return false;
  return manifest.sources.every(isManifestSource);
}

/**
 * Ordre de chargement : effectif croissant (afficher vite les petites
 * sources), départage déterministe par `id`.
 */
export function planSourceOrder(sources: ManifestSource[]): string[] {
  return [...sources]
    .sort((a, b) => a.count - b.count || a.id.localeCompare(b.id))
    .map((source) => source.id);
}
```

## Tâche 7 — E2E : router le manifeste + les shards

**Fichiers** : `site/e2e/helpers.ts`, `site/e2e/spa-fallback.spec.ts`

1. `e2e/helpers.ts` : remplacer les routes `**/icons.json` par un helper qui
   dérive le manifeste et les shards depuis la fixture :
   ```ts
   import icons from './fixtures/icons.small.json' with { type: 'json' };
   import summary from './fixtures/summary.small.json' with { type: 'json' };

   function splitBySource(list: typeof icons) {
     return list.reduce<Record<string, typeof icons>>((acc, icon) => {
       (acc[icon.source] ??= []).push(icon);
       return acc;
     }, {});
   }

   // Dans la fonction d'installation des routes :
   const bySource = splitBySource(icons);
   await page.route('**/index.json', (route) =>
     route.fulfill({
       json: {
         schemaVersion: 2,
         catalogVersion: 'e2e-fixture',
         counts: { total: icons.length },
         sources: Object.entries(bySource).map(([id, arr]) => ({
           id,
           count: arr.length,
         })),
       },
     })
   );
   await page.route('**/icons-by-source/*.json', (route) => {
     const source = new URL(route.request().url()).pathname
       .split('/')
       .pop()!
       .replace(/\.json$/, '');
     route.fulfill({ json: bySource[source] ?? [] });
   });
   await page.route('**/summary.json', (route) => route.fulfill({ json: summary }));
   ```
   (Retirer les routes `**/icons.json`.)
